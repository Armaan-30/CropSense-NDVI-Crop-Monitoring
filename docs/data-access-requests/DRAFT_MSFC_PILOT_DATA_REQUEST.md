# Draft request for an MSFC farm-boundary pilot

This is a draft for the user to review and submit to the Maharashtra State
Farming Corporation (MSFC). It has **not** been sent. The official MSFC site
describes Corporation-managed farms and lists its Pune office at Survey No.
270, Bhanduli, Senapati Bapat Road, Pune 411016, with telephone numbers
020-25650551 and 020-25659553. Confirm the current recipient and submission
route with MSFC before sending. Do not send personal farmer records by email.

**To:** Managing Director / Farm Management Branch, Maharashtra State Farming Corporation Ltd.

**Subject:** Request for permission to use a non-personal farm boundary layer for an academic CropSense pilot

Dear Sir/Madam,

I am a student/intern developing CropSense, an academic project that uses
Sentinel-2 satellite imagery and NDVI to summarize vegetation conditions over
selected agricultural fields. I request guidance on whether MSFC can authorize
a small pilot on one Corporation-managed farm or block in **[name/location]**
for **[season and year]**.

If approved, the minimum useful data would be:

- Polygon/MultiPolygon boundaries for the selected farm or field blocks, in
  GeoJSON or GeoPackage format, with coordinate reference system documented;
- stable non-personal field IDs and cultivated area in hectares, if available;
- crop/season labels only if MSFC approves their sharing;
- the dataset date, known limitations, and the applicable license or written
  usage terms.

CropSense does not need farmer names, Aadhaar numbers, phone numbers, or
ownership records. Please specify whether the permission covers local storage,
processing against public Sentinel-2 imagery through Google Earth Engine, and
display of derived field-level NDVI summaries in a non-public student project.
Please advise any required agreement, security controls, attribution, or
approved transfer method. If MSFC cannot provide the boundary data, please
direct me to the authorized custodian or application process.

This request is for a limited technical pilot. It does not imply that MSFC
boundaries represent all Maharashtra farms or establish statewide coverage.

Thank you,

**[Your full name]**

**[College / internship program]**

**[Official email and phone]**

## What to do before sending

1. Fill in your identity, college/internship program, target farm/location, and
   season. Use your institution's official email if available.
2. Attach a short project description only; do not include credentials or
   private farmer records.
3. Contact MSFC using the phone numbers above or its official website's Contact
   Us route to confirm the correct recipient and secure data-delivery method.
4. Keep the written approval and the data-use terms. Share only the approval
   reference and sanitized boundary file with the project.

MSFC's public site describes Corporation land and farm operations, but that
does not itself grant permission to obtain or reuse parcel boundaries. Any
dataset must be explicitly authorized before importing it into CropSense.
